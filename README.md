IAM Active Directory Lab

Overview

This project demonstrates a hands-on Identity and Access Management (IAM) lab using Active Directory and Microsoft Entra ID.

Objectives

- Understand user and group management
- Implement Role-Based Access Control (RBAC)
- Explore authentication mechanisms
- Learn identity lifecycle management (Joiner-Mover-Leaver)

Tools Used

- Active Directory
- Microsoft Entra ID (Azure AD)

Tasks Performed

- Created and managed users and groups
- Configured security groups
- Applied RBAC roles
- Explored Multi-Factor Authentication (MFA)
- Understood Single Sign-On (SSO)

Learning Outcome

This lab helped me understand how organizations manage identities, authentication, and access control securely in real-world environments.
